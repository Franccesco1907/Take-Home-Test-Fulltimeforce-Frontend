# GitHub commit history frontend

React/TypeScript interface with Tailwind styles for listing and filtering repository commits.

1. Start the [backend](https://github.com/Franccesco1907/Take-Home-Test-Fulltimeforce-Backend) on port 8080. Change `src/config.ts` if its URL differs.
2. Run `npm ci`, then `npm start`; open `http://localhost:3000`.
3. Build with `npm run build` (output: `build/`). Run tests with `npm test -- --watchAll=false`.
